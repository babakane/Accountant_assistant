Manual / Local Transformers

A browser-only HTML file cannot execute Python transformers code directly. The snippets below are the local/manual path for Qwen; the API providers above are the quick path from the browser.
from transformers import AutoTokenizer, AutoModelForCausalLM

tokenizer = AutoTokenizer.from_pretrained("Qwen/Qwen3-0.6B")
model = AutoModelForCausalLM.from_pretrained("Qwen/Qwen3-0.6B", device_map="auto")
messages = [
    {"role": "user", "content": "Who are you?"},
]
inputs = tokenizer.apply_chat_template(
    messages,
    add_generation_prompt=True,
    tokenize=True,
    return_dict=True,
    return_tensors="pt",
).to(model.device)

outputs = model.generate(**inputs, max_new_tokens=40)
print(tokenizer.decode(outputs[0][inputs["input_ids"].shape[-1]:]))

# Alternative pipeline / GGUF path
from transformers import pipeline

pipe = pipeline("text-generation", model="Qwen/Qwen2.5-Coder-1.5B-Instruct-GGUF")
messages = [
    {"role": "user", "content": "Who are you?"},
]
print(pipe(messages))

Project Reports

Create a research/accounting report for a project or period. The report searches indexed documents, receipts, contracts, décharges and project evidence.

Example

Project year: 2025
Currency: XOF

The assistant searches available sources for project documents and identifies supporting accounting records.

Report process

  1. Search project/source metadata
  2. Search OCR text
  3. Identify contracts and project documents
  4. Identify receipts and invoices
  5. Identify décharges
  6. Match supporting accounting documents
  7. Remove duplicate document context
  8. Calculate totals by currency
  9. Generate report
